# Palworld 1.0 Guide Hub

An English static guide site MVP focused on Palworld Version 1.0.

This project is a focused guide hub, not a full wiki or database. It covers beginner onboarding, returning player prep, server setup, base building, Version 1.0 changes, new Pals, World Tree, and FAQ content with cautious pre-release wording.

## Local Development

```bash
npm install
npm run generate:assets
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- No login, membership, comments, or admin backend.
- Uses custom generated fan-made visual assets only.
- Does not use the official Palworld logo as the site logo.
- All pages include SEO title, meta description, canonical, and Open Graph tags.
