# 技术栈与架构

更新时间：2026-07-12

## 技术栈

- Astro 静态站。
- TypeScript 数据文件管理文章。
- 原生 CSS，无前端框架。
- Node 脚本生成非官方 PNG 视觉资产。
- 站内视频：H.264/AAC fMP4 HLS、原生 `<video>`、`hls.js`。

## 关键依赖

- `astro`
- `hls.js`

## 数据流

- 文章数据集中在 `src/data/guides.ts`。
- 分类页和文章页从同一数据源渲染。
- `src/pages/[...slug].astro` 根据文章 slug 生成静态文章页面。
- 视频元数据同样集中在 `src/data/guides.ts`；`GuideVideo.astro` 渲染 HLS 播放器和章节按钮。
- 视频分片位于 `public/media/<video-slug>/`，生产构建复制到 `dist/media/`。
- 视频页输出单个 `VideoObject`，使用 HLS manifest 作为 `contentUrl`。

## 部署方式

首版适合 Cloudflare Pages、Netlify 或 Vercel 静态部署。部署后应设置：

```text
PUBLIC_SITE_URL=https://真实域名
```

## 技术决策记录

- 首版不引入 CMS，减少上线阻力。
- 不使用官方 Logo 或截图，先用自制非官方视觉资产。
- 不使用 Tailwind，避免首版依赖过多。
- 无需登录播放不依赖 YouTube iframe；少量视频先随 Pages 部署，媒体增长前迁移 R2/Stream。
